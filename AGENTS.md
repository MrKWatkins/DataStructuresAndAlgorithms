# Repository conventions

- The solution and both projects live under `src`. Use the `.slnx` solution.
- Target .NET 10; keep package versions in `src/Directory.Packages.props`.
- Use NUnit on Microsoft Testing Platform and `MrKWatkins.Assertions` fluent assertions.
- Keep workflows small by using `MrKWatkins/build`; this repository has no documentation site.
