# DataStructuresAndAlgorithms

[![Build and Test](https://github.com/MrKWatkins/DataStructuresAndAlgorithms/actions/workflows/build.yml/badge.svg)](https://github.com/MrKWatkins/DataStructuresAndAlgorithms/actions/workflows/build.yml)

Example code for various data structures and algorithms, targeting .NET 10.

Build and run the NUnit tests with the .NET 10 SDK:

```sh
dotnet build src/DataStructuresAndAlgorithms.slnx -c Release
dotnet test --solution src/DataStructuresAndAlgorithms.slnx -c Release
```
